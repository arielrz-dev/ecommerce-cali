# API de E-commerce # ecommerce-cali version 2 - with Mongo


## Descripción

Esta API proporciona una base sólida para construir aplicaciones de comercio electrónico. Permite gestionar de manera eficiente productos, usuarios, pedidos y otras funcionalidades esenciales.

## Características

- **Gestión completa**: Permite crear, leer, actualizar y eliminar productos, usuarios , pedidos , etc.
- **Documentación interactiva**: Incluye una documentación detallada y actualizada generada automáticamente con Swagger, facilitando la integración de la API en otras aplicaciones.

## Tecnologías

- **Node.js**: Entorno de ejecución JavaScript de alto rendimiento.
- **NestJS**: Framework de Node.js para construir aplicaciones del lado del servidor, que utiliza TypeScript y promueve la modularidad y la mantenibilidad.
- **TypeScript**: Superconjunto de JavaScript que agrega tipado estático para una mejor mantenibilidad y detección de errores.

## Instalación

1. Clona el repositorio:

   ```bash
   git clone https://github.com/usuario/ecommerce-api.git
   ```

2. Navega al directorio del proyecto:

   ```bash
   cd ecommerce-api
   ```

3. Instala las dependencias:
   ```bash
   npm install
   ```

## Ejecución

1. Para iniciar la API en modo desarrollo:

   ```bash
   npm run dev
   ```

La API estará disponible en http://localhost:3000

## Documentación

Accede a la documentación interactiva de la API en Swagger UI: ## http://localhost:3000/info.
Aquí encontrarás una descripción detallada de cada endpoint, los parámetros que acepta y los posibles resultados.
